# 수학의 질문들 — 집필 참고

## 승인 범위

시리즈명과 아래 아홉 장의 제목·순서는 승인됐다. 현재는 공개 예정 목차만 등록한다. 장 본문과 장 Markdown 파일은 만들지 않는다. 이후 본문 집필·공개는 별도 요청으로 진행한다.

목차 정본: `_data/post_books.yml`의 `questions-in-mathematics`. 이 문서는 Jekyll 공개 출력에서 제외되는 집필 자료다.

## 집필 기준

`docs/writing-convention.md`를 매번 읽고 적용한다. 질문에서 시작하되 모든 장을 같은 형식에 맞추지는 않는다. 각 글은 따로 읽어도 이해할 수 있게 쓰며 연결되는 장은 참조한다. 소수정리 → 제타함수 → 리만 가설, 불완전성 → 정지 문제의 연결을 살린다.

쉬운 설명 뒤에는 정확한 정의·조건·핵심 논증을 둔다. 비유가 실제 개념을 대신하지 않도록 연결과 한계를 설명한다. 독자가 설명을 듣는 데 그치지 않고 가능한 범위에서 논증을 따라갈 수 있게 한다. 가상 실험과 사례는 가상임을 밝힌다.

정리·가설·역설을 구분한다. 증명된 결과, 출처의 주장, 미확인 결과를 같은 확실성으로 쓰지 않는다. 리만 가설 관련 새 원고나 AI 성과를 다룰 때는 집필 시점의 원문과 독립 검증 상태를 다시 확인한다. 이번 대화의 평가를 수학적 사실이나 학계 합의로 인용하지 않는다.

향후 추가 장은 별도 승인 후 목차 정본에 등록한다. 승인되지 않은 후보를 공개 예정 목차에 넣지 않는다.
