# NASA 데이터셋 읽고 해석하기

## 1. 학습을 시작한 이유
- **NASA Space Apps Challenges 참가 준비.**
- 데이터셋을 찾고 읽는 과정에서 궁금했던 점.
- 이번 학습에서 알아보려는 것.

11월 14-15일에 NASA에서 열리는 [Space Apps Challenges 해커톤](https://www.spaceappschallenge.org/2026/local-events/seoul/)에 참가하게 됐다.
이 해커톤을 간략히 설명하자면 NASA와 파트너 우주기관의 오픈 데이터를 활용해 지구와 우주를 위한 솔루션을 만들어내는 해커톤이다.

## 2. 공개된 데이터로 무엇을 알아볼 수 있을까
- NASA의 공개 데이터 살펴보기.
- 지표면 반사율(Surface Reflectance) 자료와 식생지수(Vegetation Index) 자료 만나기.
- “지금은 풀이 무성한 뚝섬한강공원인데, 과거에도 이 자리는 이런 모습이었을까?”라는 질문 떠올리기.

## 3. 질문에 맞는 데이터 고르기
- 비교하려는 장소와 시기 정하기.
- 관측 기간과 공간 해상도(Spatial Resolution) 확인하기.
- 후보를 비교하고 사용할 자료 선택하기.

## 4. 공식 문서에서 데이터의 의미 확인하기
- 공식 소개, 사용자 가이드(User Guide), 메타데이터(Metadata)의 역할.
- 필요한 정보를 담은 절과 항목 찾기.
- 관측 대상과 처리 방식, 사용 시 주의사항 읽기.

## 5. 실제 파일을 열고 값 읽기
- 원하는 장소와 시기의 파일 찾기.
- 파일 구조와 변수, 밴드(Band) 살펴보기.
- 단위, 스케일 계수(Scale Factor), 결측값(Fill Value) 해석하기.
- 품질 정보(Quality Assurance) 확인하기.

## 6. 과거와 현재 비교하기
- 장소와 계절, 관측 조건 맞추기.
- 영상과 관측값에서 차이 살펴보기.
- 식생지수가 필요한지 판단하고 활용하기.

## 7. 무엇을 알았고, 무엇은 알 수 없었는가
- 처음의 질문에 답하기.
- 관측한 차이와 그 원인에 대한 추측 구분하기.
- 자료와 비교 방법의 한계 정리하기.
- 다른 데이터셋에도 적용할 읽는 순서 정리하기.
