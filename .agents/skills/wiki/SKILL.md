# Wiki

사용자가 요청한 주제·문서와 작업 범위를 확인한다.
먼저 저장소 루트의 `AGENTS.md`, `docs/writing-convention.md`,
`docs/wiki-authoring.md`를 읽고 따른다. 작업 기준의 정본은
`docs/wiki-authoring.md`이며 이 스킬에 복제하지 않는다.
특히 정본의 「본문만으로 이해할 수 있는 범위」·「인지과학을 고려한 설명 설계」·
「이해 공백 검토」를 따라, 선행 개념과 정상 사례에서 동작·보장·실패로 이어지는
자기완결적 본문을 만든다. 정적 검사 통과를 독자의 숙달 증명으로 보고하지 않는다.
관계·실행 경계·분기·시간 순서를 그림으로 설명할 필요가 있으면
`.agents/skills/diagram/SKILL.md`를 읽어 기존 도식과의 중복을 판정하고 작성·검증한다.

대상이 없으면 대상만 묻는다. 질문·평가 요청은 조회와 제안으로 끝내고,
작성·수정 요청일 때만 승인된 범위에서 작업한다.
특정 모델·CLI·전역 스킬 설치에 의존하지 않는다.
스킬 자동 탐색이나 슬래시 호출 지원은 사용 중인 도구의 기능이며,
지원되지 않으면 이 파일을 직접 읽어 동일한 절차를 수행한다.
