## Variant: pgLang-inspired Archive Ledger

### Design stance
`pg-lang.com`의 외형을 복제하지 않고, 날짜와 짧은 기록이 단일 흐름으로 누적되는 구성 원리를 공개 아카이브 홈에 번역한다. 기존 004는 유지하며 이 안은 별도 비교안이다.

### What changed from 004
- 큰 세리프 마스트헤드, 장 번호, 3열 카드, 검은 Reviews 섹션, 반복 화살표 제거
- Wiki·Reviews·Essay를 날짜순 한 목록에 혼합
- Wiki와 Reviews는 상위 사이트 구조가 아니라 필터 가능한 현재 아카이브로 표현
- 리뷰 표지는 모든 카드에 강제하지 않고 해당 기록을 펼칠 때만 표시
- 저장소의 실제 제목, 날짜, 작성자, 유형, 평점을 사용
- 004에 등장한 Wiki·Reviews 항목을 유지하고 날짜가 없는 리뷰는 별도 구간에 명시

### Reference boundary
가져온 것: 작은 헤더, 큰 빈 공간, 날짜/본문의 2열 리듬, 카드 없는 누적 목록, 선택적 미디어.

가져오지 않은 것: pgLang의 로고, 아이콘, 문구, 고유 콘텐츠, 정확한 간격·서체·인터랙션.
